## How to Run
Since these are mostly standalone Java programs, you can run them directly from the terminal or using an IDE like Eclipse.

**To run via terminal:**
1. Navigate to the specific day's folder:
   ```bash
   cd day-1
   ```
2. Compile the Java file:
   ```bash
   javac HelloWorld.java
   ```
3. Run the compiled class:
   ```bash
   java HelloWorld
   ```
*(Note: For programs using packages (like Day 10 and Day 11), compile and run from the root source directory using the fully qualified class name.)*
